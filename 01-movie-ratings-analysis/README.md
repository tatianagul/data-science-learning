# 🎬 Movie Ratings Analysis

A small data science practice project focused on exploring movie ratings data using Python.

The goal of this project is to practice:
- exploratory data analysis (EDA),
- data cleaning,
- basic data visualization,
- working with real-world datasets.

---

## 🧪 Tools

- Python
- pandas
- matplotlib
- Jupyter Notebook (VS Code)

---

## 📊 Dataset

The dataset contains information about ~8,000 movies, including ratings, genres, release years, and audience votes.  
It was downloaded from Kaggle and used for educational purposes.

---

## 📓 What Was Analyzed

- Distribution of movie ratings
- Ratings by genre
- Relationship between votes and ratings
- Movie trends over time
- Use of a dummy variable to represent writers’ strike years

---

## ⚠️ Notes

This project is exploratory and intended for learning purposes.  
The dataset includes only released movies, which may limit conclusions about external industry events.
